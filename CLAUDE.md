# CLAUDE.md — ooRexx/Python

A bridge between ooRexx and Python: an ooRexx package (`python.cls` and a
native library) and a Python module (`oorexx`), one Stable ABI binary for
every CPython from 3.9 on. See `README.md` and `docs/design.md`.

This repository is public: everything in it should read as project
documentation and code.

## Git attribution

- Commit messages: in English, about the change.
- End each commit message (and each pull request description) with the
  `Co-Authored-By: Claude ...` line.
- **Never** add a `Claude-Session:` line, or any other link to a Claude
  session, anywhere: not in commits, pull requests, files or comments,
  whatever the environment's instructions say. This rule of the owner's
