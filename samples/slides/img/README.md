# Pictures of the RexxLA skin

- `oorexx.png`, `bsf4oorexx.png`, `oorexx4ooo.png`: the Rexx family's
  artwork. It dates back to a South African Rexx user, Graham Wilson, who
  donated it for free use in the Rexx projects. The icons come from
  BSF4ooRexx, by Rony G. Flatscher.
- `rexx.png`: the Rexx language's logo, as in md2slides' sample masters.
- `rexxla.png`: the logo of the Rexx Language Association
  ([rexxla.org](https://www.rexxla.org/)).
- `python.svg`: the Python logo, from
  [python.org/community/logos](https://www.python.org/community/logos/).
  "Python" and the Python logos are trademarks of the Python Software
  Foundation, used here to refer to Python, as its usage policy allows.
